## Overview

MatGabor is a framework for editable dynamic 3D Gaussians. It attaches material-space Gabor carriers — with directly controllable wavelength, orientation, phase, and RGB amplitude — to persistent Gaussian identities, and updates the carriers by standard inverse-transpose transport, so an authored pattern stays registered to the same material points under stretch and shear.

A covariance-aware RGB interface projects the transported frequencies with the deformed covariance into pixelwise color residuals, while preserving geometry, opacity, and alpha compositing.

Experiments on six PhysGaussian scenes show the framework outperforms six alternative routes, with Ref-MAE reduced by 97.6% relative to rotation-only transport.
